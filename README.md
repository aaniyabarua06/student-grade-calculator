# 🎓 Student Grade Calculator

So, this is one of my first Python projects. Just a little something I built while learning Python and putting my coding skills to use.

Basically, it takes marks for three subjects, calculates the total and average, and gives you a grade. Pretty simple, but hey, we all start somewhere. ✨

### ✨ Features
- Takes your name and marks as input
- Calculates total marks and average
- Gives you a grade based on your performance
- Checks for valid marks (0–100)
- Prints out a neat little student report
